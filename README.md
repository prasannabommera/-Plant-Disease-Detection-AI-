Plant Disease Detection AI is an artificial intelligence-based project that helps farmers identify diseases in plants by analyzing images of plant leaves. The user uploads or captures a leaf image, and the AI model analyzes it to detect possible diseases.

The system can provide:

🌿 Disease identification from leaf images
🔍 Early detection of plant diseases
💡 Basic information about the detected disease
🛠️ Suggested prevention and treatment methods
📱 A simple and user-friendly interface for farmers

Technologies: Python, Machine Learning/Deep Learning, CNN, OpenCV, and HTML/CSS/JavaScript.
